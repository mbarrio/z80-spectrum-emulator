    This is the registered version of Z80/WinZ80, the Sinclair ZX Spectrum
    emulators for DOS and Windows.

    ==========================================================================

    Installation:
    -------------

    To install the Windows version,

        - In Win 95/NT: Start "INSTALL.EXE" from DOS prompt or Windows desktop
        - In Win 3.x:   Start "INSTALL.EXE" from Windows desktop

    To install the DOS version,

        - Type "INSTALL <path-for-Z80>", for example:

            INSTALL c:\z80

    Note that, if you wish to install into another directory 
    e.g. INSTALL c:\spectrum\z80, then the 1st directory must already exist.
